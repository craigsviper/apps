## Quick decision guide — do I need #4 and/or #5?

Both are **optional, one-time, host-server-only** setup steps. Nothing else
in the app needs either of them — Draw Points, all the bulk-edit tools,
Sweep Jobs, Inspections, Backup & Sync, etc. all work with neither one set
up.

- Want to click/lasso/box-select existing roads instead of drawing every
  point by hand in Areas & Roads → Edit Road? → **#4, `road-data-setup`**
- Want a "🛰️ Snap to Roads" button that corrects a drawn segment onto real
  OSM road geometry (and, as of v73.75, have that happen automatically
  whenever you press "✓ Add to Segment")? → **#5, OSRM**
- Want both? Do them in either order — they're independent, separate data
  built from separate scripts (`extract-roads.sh` vs `setup-osrm.sh`).

## Keeping this folder in sync

This folder is generated by copying the canonical files from their real
locations (listed above). If you edit a guide, edit the canonical copy and
re-copy it here — don't edit only the copy in `guides/`, or the two will
drift apart. See `.claude/skills/rsw-field-app-release/SKILL.md` for the
full release checklist, which now includes updating `guides/` alongside
the canonical files on every doc-affecting change.
